# TabDoze Privacy Policy

Effective: 2026-07-10

TabDoze does not collect, sell, transmit, or share personal data. It has no account system, analytics, telemetry, advertising SDK, or background network service.

## Data Stored by the Extension

TabDoze stores the following data in Chromium extension storage:

- sleep timeout and keep-awake domains
- current-session inactivity timestamps
- successful-discard counts and estimated memory-relief history
- onboarding and scheduler migration state

This data is used only to operate the extension. Settings stored with `chrome.storage.sync` may be synchronized by the browser when the user has enabled browser sync; that synchronization is controlled by the browser vendor, not TabDoze.

## Browser Data Access

TabDoze reads tab URLs, titles, activity state, and discard state to decide whether a tab is eligible to sleep and to render its local interface. It does not upload browsing data.

## User-Initiated Links

The extension includes links to the project's GitHub pages and optional share actions on the statistics page. A network request occurs only when the user explicitly opens one of those links.

Questions and reports: [GitHub Issues](https://github.com/mrdear/tabdoze/issues).

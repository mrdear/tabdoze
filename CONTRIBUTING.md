# Contributing to TabDoze

1. Create a focused branch from `main`.
2. Keep the committed `manifest.key` and historical storage keys unchanged.
3. Run `npm test` and `npm run check`.
4. Load the repository with **Load unpacked** and verify the changed workflow in Chromium.
5. Open a pull request describing behavior, risk, and verification.

Do not add analytics, remote code, or claims that estimated memory relief is measured process memory.
